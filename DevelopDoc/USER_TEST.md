## 4. 끝난 뒤 테스트 회원 데이터 지우기

**왜**: Supabase가 로컬·운영 하나(`sleepyhead`)라 참가자 계정이 실제 서비스 DB에 남는다. 원하는 참가자 데이터는 그 자리에서 지우고, 진행자 시험 데이터는 **본인 것만** 지운다 (PHASE5_PLAN §1-8).

| # | 누가 | 방법 | 확인 |
|---|---|---|---|
| 1 | 참가자 (본인 계정으로 로그인한 채) | 화면 위 [내 분석] → `/me` 맨 아래 **회원 탈퇴** → [탈퇴하기] → 확인 창에 `탈퇴` 입력 → 확인. 저장된 분석·질문 기록·사용량·로그인 정보가 모두 지워진다 (A6, WU-204 — 되돌릴 수 없다) | 탈퇴 뒤 첫 화면으로 돌아가고, 다시 로그인하면 약관 동의부터 시작 |
| 2 | 참가자가 이미 떠났는데 지워 달라고 하면 | 병준님 [OPS_RUNBOOK](./OPS_RUNBOOK.md)의 "회원 데이터 지우기" 절차(관리자 — 운영 DB 쓰기라 통합/배포 담당만). 진행자가 SQL을 직접 실행하지 않는다 | OPS_RUNBOOK 기록 |
| 3 | 진행자 | 테스트 중 진행자 계정으로 만든 분석은 그대로 둬도 된다(시연 대안 결과로 쓸 수 있음). 지우려면 진행자 계정으로 1번 | |

- 탈퇴는 회원 데이터만 지운다. 기업 재무·주가·뉴스 캐시처럼 회원과 상관없는 데이터는 남는다(다음 질문이 빨라진다)
- 표 §0의 "끝난 뒤 탈퇴 원함"이 "예"인 참가자는 1번을 마칠 때까지 진행자가 옆에서 본다
